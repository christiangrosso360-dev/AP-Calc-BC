Correct by construction

The picture is drawn by a deterministic engine from the actual function — not sketched by an AI. Intersections, areas and tangents are solved, not guessed.

Actually interactive

Curves draw themselves in, Riemann rectangles refine, points ride the curve. It is a live widget, not a screenshot of a graph.

Works anywhere

One iframe. No script to install, no account, nothing to configure. It resizes to whatever box you put it in.

Using it in your own tools

The widget is driven entirely by the URL, so you can generate embeds programmatically. The s parameter is a base64-encoded scene: a small JSON object with functions, an optional domain, and optional extras like shade, riemann, polar, field or analysis.
